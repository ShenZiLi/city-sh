## 查看入口

- `npm run dev` 后打开终端给出的本机地址，加 `/art-lab.html`：实际三维局部样片。
- 同一地址加 `/art/renovation/review.html`：色稿、专用图集、原图及提示词。
- 原版主页仍保留，避免用未通过的样片覆盖已交付版本。

## 制作与资源约束

- 新增绘画资源均实际通过内置 image_gen 生成，原图、提示词、参考图校验值、实际尺寸在 `art/renovation/manifest.json`。
- 原图保持不变，预览只缩小压缩；天空由同一图集裁切为三个色带。
- 三处地标及两类配景在 Blender 中离线构建、保存源文件，再导出GLB。浏览器只加载资产；这不是手工雕刻模型，制作方式如实记录为离线参数化几何与生成美术结合。
- RT01的钟面数字有瑕疵，该象限弃用。模型使用立体刻度与指针，不把错误数字当作合格细节。
- 新图集请求2048级，工具实际返回1254×1254。未放大冒充更高精度；纹理密度尚需近景验收，该差异属于后续质量评估项。
- 三次并发素材请求发生连接失败，后续改用逐张内置工具重试成功。没有调用外部付费API。
- 运行资产只标记候选或已接入；文件、类型和功能检查不自动赋予视觉“已验收”状态。
