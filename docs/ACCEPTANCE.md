# 成品验收记录

验收日期：2026 年 10 月 20 日（上海时间）。验收对象：本目录 dist 的生产构建，通过只监听本机的 4173 端口运行。

## 自动与功能验收

- **13 项单元测试通过**：地标与河道关系、河道宽度、十三个唯一地标、苏州河口开口、固定随机序列、2.4 秒时段过渡、中断过渡、减少动态效果、长时间反向交通循环、单指轻点、多指缩放、拖动回原点、取消手势恢复。
- **TypeScript 类型检查与生产构建通过**。
- **25 项浏览器功能检查通过**：三时段、连续切换、相机保持、四个镜头、键盘与按钮同步、标签、说明、聚焦、画质、拖动暂停、帮助面板、全屏受限提示、PNG 数据导出、无未预期运行错误、无失败资源请求。原始记录见 output/functional-report.json。
- **8 项异常与恢复检查通过**：缺失素材编号提示、天空完整降级、WebGL 中断提示、上下文恢复、减少动态效果关闭环绕、短过渡、环境静止、释放后移除画布与诊断对象。见 output/reliability-report.json。
- **19 张原图与 16 张运行贴图完整**；D01、D02 的 Alpha 最小值为 0、最大值为 255。原图尺寸、散列与提示词见 art/manifest.json。
- **24 方位截图完成并复核**：每时段八个方位，检查地标背面、孔洞、岸线、城市覆盖及三时段表现。画册为 output/review.html，主视图为 output/screenshots/hero-day.png、hero-dusk.png、hero-night.png。
- 手机竖屏约 390×840 CSS 像素与横屏约 840×390 CSS 像素：无横向溢出，底部操作区位于视口内；以模拟视口进行检查，截图随包交付。

## 最终性能实测

测试浏览器：Windows 上的 Tabbit Chromium 153；GPU：NVIDIA GeForce RTX 5060 Ti，经 ANGLE Direct3D11。每组在完成过渡后采样 90 个帧间隔，帧率使用 requestAnimationFrame 的真实时间戳计算。

| 场景 | 实际绘制像素 | 实测平均帧率 |
|---|---|---|
| 白天／精细 | 1920×1080 | 59.96 FPS |
| 夜晚／精细 | 1920×1080 | 59.97 FPS |
| 夜晚／流畅 | 1536×864 | 59.96 FPS |

详见 output/benchmark.json。统计中的调用与三角形包含反射、阴影及后处理渲染；与仅统计单个场景通道的数字不可直接比较。

早期测试会话出现约 30 FPS，并检测到深色扩展改写配色；最终页面声明自行管理颜色主题后，重新导出了主视图与环绕图，并进行了上述实际 1080p 测量。性能结论以最终记录为准。

## 验证边界

- 本环境实测的是 Tabbit 的 Chromium 内核，未分别操作独立安装的 Chrome、Edge，也未使用实体手机进行性能测试。
- 测试容器限制原生全屏请求，已验证受限时的反馈；PNG 通过真实界面调用生成，并验证 PNG 签名与图像数据。容器下载事件不作为原生浏览器下载结果的证明。
- 作品为艺术化城市沙盘，非地理测绘、实时天气或建筑灯光时刻模拟。
