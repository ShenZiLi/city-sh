# 纸上浦江 · A City in Watercolour

一座可以环绕观看的上海陆家嘴—外滩手绘三维沙盘。黄浦江、苏州河口、13 处城市地标与 97 栋配景建筑共同构成一页微缩上海。美术由 image 生图制作，建筑为真实三维几何。

## 美术改造样片（进行中）

新方案保留360°与三时段，使用独立Blender/GLB建筑和实际image生成的专用图集。构建并启动后打开 `/art-lab.html` 查看局部实时样片，打开 `/art/renovation/review.html` 查看色稿、原图与提示词。原主页保留旧版，样片不代表全城改造完成。

用户已选择 A 作为美术方向；局部样片尚待视觉验收。完整范围与状态见 [改造计划](docs/ART_RENOVATION_PLAN.md) 和 [实施记录](docs/ART_RENOVATION_PROGRESS.md)。`npm run art:doctor` 检查Blender，`npm run art:models` 重建模型，`npm run art:prepare` 重建画册。仅运行成品不需要Blender。

## 打开作品

**从 GitHub 克隆后**，先在项目目录运行 `npm ci` 和 `npm run build`，再按下述方式启动。Git 仓库保留完整源码、美术原图和验收图集；依赖、构建目录与交付压缩包不纳入版本控制。

Windows 双击根目录的 **启动作品.cmd**，然后打开 **http://127.0.0.1:4173/**。保留启动窗口即可持续浏览，关闭窗口会停止本地服务。

运行成品仅需 Node.js 22.12 或更新版本，不需要安装项目依赖。请通过本地服务打开，直接双击 dist/index.html 无法正确加载模块。作品运行不调用远程 API，不需要 API Key。

也可以在本目录执行：

```sh
node scripts/serve.mjs
```

端口被占用时，可设置 PORT 环境变量再运行。默认服务只监听本机地址。

## 如何漫游

| 操作 | 效果 |
|---|---|
| 鼠标左键拖动／手机单指拖动 | 360° 环绕城市 |
| 滚轮／手机双指缩放 | 靠近或退后 |
| 白昼、暮色、入夜 | 约 2.4 秒的光影过渡，支持中途再次切换 |
| 全景、陆家嘴、外滩、江面 | 切换构图 |
| 点选建筑或地标名称 | 查看城市手记，再点击“靠近这处风景”聚焦 |
| 右侧环游按钮 | 开关自动环绕；手动操作会暂停环绕 |
| 右侧名称按钮 | 显示或隐藏地标标签 |
| 右侧相机按钮 | 保存带作品题签的 PNG 画面 |
| 右侧图层按钮 | 精细／流畅画质切换 |
| 数字 1、2、3 | 白昼、暮色、入夜 |
| R | 复位全景镜头，保留当前时段 |

全屏依赖浏览器允许；不支持时界面会给出提示。系统启用“减少动态效果”时，默认关闭自动环绕，环境移动静止，过渡缩短。

## 本地开发

```sh
npm ci
npm run dev
npm test
npm run check
npm run build
```

开发预览为 http://127.0.0.1:5173/。生产成品位于 dist，可部署到支持静态文件的服务；构建使用相对资源路径。

## 交付目录

- `src/`：三维模型、城市布局、时段系统、交互与界面源码。
- `dist/`：已经构建的本地成品，素材完整内置。
- `art/originals/`：19 张 image 生成原图，保留实际原始尺寸。
- `art/manifest.json`：每张图的提示词、来源类型、用途、运行路径及验收信息。
- `art/gallery.html`：可直接双击打开的美术资源画册。
- `public/assets/`：运行时 WebP 贴图与保留透明通道的 PNG。
- `output/screenshots/`：三个时段主视图与 24 方位验收截图。
- `output/`：功能验收、性能、异常恢复及移动布局检查记录。
- `docs/`：执行检查点、制作说明、验收说明。
- `scripts/prepare-assets.mjs`：由原图重新制作运行素材，不修改原图。

## 美术与场景

三套概念图仅用于确定风格；运行画面由可转动的真实几何、11 张材质贴图、3 张天空贴图和2张透明环境图组成。地标背面、环球金融中心镂空、上海中心扭转与金茂退台均为三维形体。

城市采用艺术化比例，保留两岸关系和主要轮廓，非测绘模型。黄昏与夜晚为创作光影，不使用实时天气或真实建筑灯光时刻表。

## 技术

Vite、TypeScript、Three.js；OrbitControls 控制相机；MeshToonMaterial 结合 AI 手绘颜色贴图；高档使用平面反射与轻量夜景柔光；低档减少树木、隐藏车辆和云层、关闭反射与柔光并降低阴影分辨率。

地标介绍是针对本件艺术沙盘编写的观赏说明。地理构图参考上海官方陆家嘴与外滩资料，链接见 docs/MAKING.md。第三方代码许可见 package-lock.json 对应依赖与 THIRD_PARTY_NOTICES.md。
